## 📖 Что это такое

**Linux Quest** — интерактивная игра-тренажёр, которая учит Linux от нуля до продвинутого уровня. Ты работаешь в **настоящем терминале** прямо в браузере (или desktop-приложении), выполняешь задания, получаешь XP, повышаешь ранг и открываешь новые зоны карты мира.

**Главная идея**: не читать теорию, а **сразу делать** — вводить реальные команды Linux и видеть результат. Как в настоящем терминале, только безопасно (файловая система виртуальная — сломать нельзя).

## 🎯 18 миссий — от `pwd` до `systemctl`

Полный путь обучения разбит на **18 миссий**, в каждой 4–6 заданий.

### 📖 Основы (миссии 1–6)

1. **Знакомство** — `whoami`, `pwd`, `ls`, `uname -a`
2. **Навигация** — `cd`, `cd ~`, `cd /etc`, чтение `syslog`
3. **Файлы** — `mkdir`, `touch`, `cp`, `mv`, `rm`, `echo >`
4. **Текст** — `grep`, `head`, `tail`, `wc`, `sort`, `uniq`
5. **Права** — `ls -l`, `chmod 755`, `chmod 644`, `chown`
6. **Процессы** — `ps`, `df`, `free`, `uptime`, `id`

### 🚀 Продвинутое (миссии 7–14)

7. **Пайпы и редиректы** — `|`, `>`, `>>`, `;`
8. **Продвинутое** — `awk`, `sed`, `find`, `alias`, `export`
9. **Vim** — создание и редактирование файлов
10. **Bash-скриптинг** — переменные, `for`, `if`, `then`
11. **Сети** — `ip a`, `ip r`, `ping`, `ss`, `curl`
12. **Systemd** — `systemctl status/enable/list-units`, `journalctl`
13. **Пакеты** — `apt update/install/remove`, `dpkg -l`
14. **Архивы** — `tar -cf`, `tar -xf`, `gzip`, `zip`, `unzip`

### 🏆 Финал (миссии 15–18)

15. **Мастер Linux** — комбо-задания (`grep` + `sort` + `chmod`)
16. **Диагностика** — `top`, `htop`, `lsof`, `dmesg`, `strace`
17. **Пользователи** — `useradd`, `passwd`, `groups`, `/etc/sudoers`
18. **Linux Operator** — комплексная: логи + порты + скрипты + бэкап

## 📝 Мини-редактор Vim

Введи `vim filename.txt` или `nano filename.txt` — откроется **встроенный редактор**:

- **Ctrl+S** — сохранить
- **Esc** — выйти (с автосохранением)
- Подсветка статуса: `-- INSERT --` / `-- NEW FILE --`
- Показывает размер файла при сохранении

Идеально для миссий 9, 10, 15, 18, где нужно создавать скрипты.

## 🌐 Разделы знаний (6 областей)

### 1. Filesystem (Файловая система)
- Иерархия: `/`, `/home`, `/etc`, `/var`, `/tmp`, `/usr`
- Пути: абсолютные, относительные, `~`, `..`, `.`
- Метаданные: права, владелец, размер, время

### 2. Bash (Оболочка и скрипты)
- Пайпы, редиректы, цепочки
- Переменные, `$VAR`, `export`
- Алиасы, история команд
- Условия `if`, циклы `for`
- Скрипты в файлах

### 3. Kernel (Ядро и процессы)
- Просмотр процессов (`ps`, `top`)
- Сигналы (`kill`)
- Логи ядра (`dmesg`)
- Трассировка (`strace`)

### 4. Network (Сети)
- IP-адреса, маршруты
- Порты и соединения (`ss`, `netstat`)
- HTTP-запросы (`curl`, `wget`)
- Диагностика (`ping`)

### 5. Sysadmin (Администрирование)
- Systemd-сервисы
- Управление пакетами (`apt`, `dpkg`)
- Пользователи и группы
- Ресурсы: диск, память, CPU

### 6. Диагностика
- Логи системы (`journalctl`, `/var/log`)
- Мониторинг в реальном времени
- Поиск проблем (`lsof`, `dmesg`)
- Анализ производительности
